# Web Anatomy — 竞品 Profile

**URL**：https://www.webanatomy.ai/landing-page-analyzer
**生成日期**：2026-08-10
**深度**：quick scan

## 定位

面向 AI agent 的真实页面 benchmark 库，同时提供 Landing Page 分析。产品强调“不是训练数据猜测”，而是用真实公司页面 section、截图和评分帮助用户改版。

## 产品与报告

- URL 分析页面公开写明约 2 分钟。
- 桌面/移动截图、约 60–63 个标准、0–100 分数；不同官方入口的标准数量口径不完全一致。
- 标注截图、严重度、优先级修复、paste-ready rewrites。
- 可与官方宣传的 3,500–4,000 个 scored sections、400–650 家公司 benchmark 比较；这些数字是页面口径，不是第三方审计结果。

## 价格

- 免费：公开 benchmark，分析器有 1 个分析额度。
- Pro：€9/月；更高计划 €19/月。
- 定制 UX 竞品分析：€149 一次。

## Strengths / Weaknesses

**Strengths**：benchmark 数据、视觉证据、行业和 section 过滤、agent/MCP 传播路径。
**Weaknesses**：更像 benchmark 和设计方法工具；对“为什么这页不转化”的业务解释不如一个窄 CRO 产品直接。

## 对 AI Website Critic 的启示

不能把截图、分数、改写当作独有功能。若聚焦 SaaS 首页注册转化，必须在报告证据和行动任务上做得更直接。
