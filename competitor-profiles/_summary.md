# 竞品扫描摘要

**扫描日期**：2026-08-10
**深度**：quick scan
**比较对象**：Web Anatomy、Cruelx、Conversion Probe、Landing Analyze、HubSpot Website Grader、Semrush SEO Checker

## 市场概览

市场已经存在两条相邻路线：一条是免费技术/SEO Grader，用分数教育用户并导向更大的营销产品；另一条是新一代 AI Landing Page/Website Audit，用截图、文案、转化心理、优先级修复和付费报告获取收入。AI Website Critic 若只复制“输入 URL + AI 分数”，没有明显空白；机会在于聚焦 SaaS 首页的注册/预约转化，并把每条建议绑定到真实页面证据和可直接替换的文案。

## 关键洞察

1. 免费报告必须有用，否则无法建立信任；但最完整的优先级行动计划、改写和 PDF 才是付费边界。
2. 一次性报告价格已经被公开市场压到 $7–$8.99 附近；$19 需要更多证据和更强的业务上下文。
3. 订阅只有在“反复复查”和“多站点/客户交付”场景中合理，不是初始默认模式。
4. 视觉截图正在成为直接竞品的共同卖点，截图本身不构成差异化；Web Anatomy 的不同官方页面对 benchmark 数量也有不同口径，不能把宣传数字当成审计指标。
5. 技术 SEO 工具和转化文案工具的交集仍然可以聚焦，但 V1 不应试图覆盖完整 SEO 平台。

## 机会与威胁

### 机会

- 面向 SaaS 创始人的首页转化诊断。
- 以“先改哪三件事”为核心，而不是输出长篇审计。
- 将报告中的问题转成可复制的文案和开发任务。
- 用真实案例和前后改动建立 benchmark，而不是先建设完整数据平台。

### 威胁

- Cruelx 已覆盖最广的功能组合和成熟价格阶梯。
- Web Anatomy 正在把页面基准、截图和 AI agent 结合起来。
- HubSpot/Semrush 可以用既有品牌和生态把免费审计变成获客入口。
- 页面抓取、视觉模型和报告生成的成本可能让“$19 一次”利润空间被低估。
