# HubSpot Website Grader — 竞品 Profile

**URL**：https://website.grader.com/
**生成日期**：2026-08-10
**深度**：quick scan

## 定位

成熟的免费 Website Grader，用简单分数帮助网站所有者理解技术健康和搜索基础。

## 产品与报告

- 100 分制。
- 四个核心方向：性能、移动体验、SEO 和安全。
- 官方强调几秒生成分数和清晰的改进建议。
- 主要是技术/SEO 基线，不是文案或买方心理诊断。

## 价格

- Website Grader 免费。
- 当前公开工具页没有展示一次性深度报告价格。

## Strengths / Weaknesses

**Strengths**：品牌信任、教育内容、技术评分容易理解。
**Weaknesses**：不回答“为什么用户不注册/购买”。

## 对 AI Website Critic 的启示

说明简单评分和即时反馈可以获得使用，但 AI Website Critic 应把 SEO 限制为证据层，把核心放在定位、文案、CTA 和转化原因。
